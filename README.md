# KLIK KLAK releases

Public home for **KLIK KLAK** releases, the 5v5 Warmachine pairing planner by
GronkSoft & QTR-Games.

**Players: get KLIK KLAK from itch.io, <https://quotemyname.itch.io/klik-klak>.**
It has the Windows installer and the Android APK.

## What lives here

The [Releases](https://github.com/QTR-Games/KLIK-KLAK-RELEASES/releases) page
holds each Windows version (`desktop-v…`):

- `KLIK.KLAK_x.y.z_x64-setup.exe`, the installer
- its `.sig` signature
- `latest.json`, the manifest the installed Windows app checks on launch

The Windows app updates itself from the newest published release here. That
check sends nothing about you or your boards. The app's source code is not in
this repository; releases are built and uploaded by its release workflow.
